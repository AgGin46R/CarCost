# Вынос строк в ресурсы

Инструмент, которым русские строки переносились из кода в `res/values/strings.xml`.
Лежит в репозитории, а не в черновиках, потому что работа не разовая: новый экран
пишется по-русски, и его строки выносятся тем же способом.

## Как пользоваться

```bash
python tools/localize/localize.py app/src/main/java/.../FooScreen.kt --prefix foo --mode compose
```

`--mode` задаёт способ обращения к ресурсам — угадать его по имени файла нельзя:

| режим | подставляется | где применять |
|---|---|---|
| `compose` | `stringResource(...)` | экраны и составные части интерфейса |
| `vm` | `getApplication<Application>().getString(...)` | `AndroidViewModel` |
| `worker` | `applicationContext.getString(...)` | фоновые задачи |
| `context` | `context.getString(...)` | службы, где поле `context` уже есть |

После прогона собрать проект. Часть ошибок повторяется от файла к файлу и чинится
автоматически:

```bash
./gradlew :app:compileDebugKotlin 2>&1 | grep "^e:" | sed 's|file:///||' \
  | python tools/localize/fixcomposable.py
```

Он помечает `@Composable` функции-словари, которые стали composable из-за того,
что начали читать ресурсы.

## Что инструмент НЕ трогает

Пропускаются строки в логах, в `Regex(...)`, в аннотациях Room и в маршрутах
навигации — они не показываются человеку, а перевод их сломает.

Отдельно **не выносились** и остаются русскими намеренно:

- `data/reference/VehicleCatalog.kt` — синонимы поиска марок: «тойота» находит
  Toyota. Перевод сломал бы подбор.
- `domain/categorization/ExpenseCategoryClassifier.kt` — ключевые слова, по
  которым категория определяется из описания. Это разбор ввода, не показ.
- `SearchViewModel.categoryRuName` — синонимы для поиска по расходам.
- Поисковые запросы в `PoiCategory` — уходят в Яндекс.Карты, которые понимают
  русский по всему региону; перевод сузил бы выдачу.
- `PrivacyPolicyScreen`, `TermsOfUseScreen` — юридические документы. Машинный
  перевод здесь создаёт риск, а не пользу.
- `CarBotEngine` — помощник разбирает русские фразы и отвечает по-русски.

## Реестр

`registry.json` хранит соответствие «русский текст → ключ». Одинаковый текст в
разных файлах получает один ключ, поэтому переводится один раз. Из реестра же
пересобирается `values/strings.xml`: строки, заведённые руками (до пометки
`<!-- Вынесено из кода -->`), сохраняются и переиспользуются.

## Переводы

`values-en`, `values-be`, `values-kk`. Непереведённый ключ Android берёт из
`values/`, то есть по-русски — приложение работает на любой стадии перевода,
ничего не ломается на полпути.

**Белорусский и казахский написаны без носителя языка.** Перед выкатом их нужно
показать тому, кто на этих языках говорит: автомобильные термины и названия
работ по обслуживанию легко получаются формально верными, но неживыми.
